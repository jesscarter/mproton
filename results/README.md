# Results

Committed here: each run's `summary.md`, its TSVs (`checks.tsv`, `runs.tsv`, `matrix.tsv`, `env.tsv`) and the mpbench JSON files.

Not committed: the raw per-run logs (`*/logs/`) and console captures (`*.log`). They are large, full of local paths, and regenerated by every run, so `.gitignore` keeps them out. When a summary says "logs in `logs/`", that folder exists only on the machine that ran the tests. Re-run `tests/ladder/run.sh` or the matrix scripts to get them.
